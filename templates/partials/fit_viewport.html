{% comment %} Fit-to-screen helper for Task Management (table + kanban). Both the table and the board scroll sideways (overflow-x), and a sticky header only sticks inside its nearest scrolling box — not the page. So instead of letting the page scroll, each element marked [data-fit-viewport] gets its own scroll area sized to the space left below the sticky toolbar (exposed as --fit-h). Headers inside then stay put while rows/cards scroll. Desktop only: on phones the table becomes cards and the page scrolls normally. {% endcomment %}
