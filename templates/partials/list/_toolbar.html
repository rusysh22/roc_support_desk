{% load custom_tags %} {% comment %} Standardized page header + search/advanced-filter toolbar for list pages. The including template supplies: - title / subtitle (optional strings — renders the page header row above the toolbar; omit both to keep just the search/filter bar, e.g. pages that put their own title in {% block topbar_actions %} instead) - create_url / create_label (optional — renders a "+ New X" button in the header row; an icon-only copy appears inside the toolbar once the header has scrolled out of view) - extra_header_template (optional string path to a small partial with extra header-row buttons alongside the create button, e.g. an "Import" link — only shown in the header row, not reproduced in the compact bar) - subtitle_extra_template (optional string path to a small partial rendered directly below the subtitle text, e.g. a mode badge or inline link) - search_placeholder (string) - search_query (current ?q= value) - filter_panel_template (optional string path to a small partial with the module's own filter fields, e.g. "desk/forms/_filter_fields.html" — Django {% include %} can't override a block from another include, so each module supplies its fields as its own tiny partial instead of a block override) - has_active_filters (bool — shows the Clear link) - active_filter_count (optional int — shown as a badge on the Advanced Filter button; when > 0 the filter panel starts open and the button is blue. A plain search never opens it. The red Clear button appears while a search or filter is active) - open_filter_count (optional int — when set, decides whether the panel starts open instead of active_filter_count; e.g. filters applied by quick chips above the list count on the badge but keep the panel closed) - result_noun (optional, unused — the row count is shown by the pagination footer's "Showing x–y of N" line) The filter panel is toggled client-side; both search and filters submit as a normal server-side GET so pagination/query params stay in sync. Scroll behaviour: the title row scrolls away normally; only the search card is sticky. Once it sticks (an IntersectionObserver watches the sentinel just above it), button labels collapse to icons. That switch changes widths only — never the toolbar's height — so the page below can't shift and re-trigger it (the old scroll-threshold version collapsed the title inside the sticky bar, which moved the scroll position and made the header flicker back and forth). {% endcomment %} {% if title %}
